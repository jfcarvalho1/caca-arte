# Caca Arte Scout Linux

Instalador Linux separado do projecto original.

## Instalar

1. Descarregue ou extraia o pacote completo do repositorio.
2. Abra a pasta `linux_install`.
3. Execute `instalar_linux.sh` a partir do terminal.

O instalador cria uma copia independente em `~/CacaArteScoutLinux`, cria ambiente Python virtual, instala os requisitos e cria um atalho no menu de aplicacoes.

Nao altera os ficheiros originais nem apaga a pasta de dados existente na instalacao.

## Abrir

Use o atalho **Caca Arte Scout** no menu de aplicacoes ou execute:

```bash
~/CacaArteScoutLinux/abrir_caca_arte_scout.sh
```
